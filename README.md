# 昔涟表情包 v2.2.0

昔涟（Cyrene）主题的 AstrBot 表情包，共 **181 张**（151 张静图 + 30 张动图），
分 10 类，可直接导入「AstrBot 表情包管理器」使用。

## 分类

| 分类 | 数量 | 适用场景 |
|---|---|---|
| happy | 24 | 开心、笑、庆祝、收到好消息 |
| love | 19 | 比心、喜爱、撒娇、亲近 |
| meow | 103 | 卖萌、可爱、日常闲聊 |
| sad | 8 | 难过、委屈、哭、需要安慰 |
| confused | 10 | 疑惑、问号、没听懂 |
| angry | 5 | 生气、不满、小小抗议 |
| sleep | 3 | 困了、想睡、晚安 |
| daily | 3 | 日常通用、带字梗图 |
| like | 3 | 点赞、认可、称赞 |
| reply | 3 | 收到、在听、等待回应 |

## 导入方法

AstrBot 后台 → 插件 → 表情包管理器 → 设置中心 → 导入与备份 → 压缩包导入，
选择 `cyrene-memes-v2.2.0.zip`。

## 文件说明

- `manifest.json`：包清单（schema_version = 1）
- `memes/<分类>/`：表情图片，静图为 WebP（≤512px），动图为 GIF（≤220px）
- `previews/cover.jpg`、`previews/overview.jpg`：预览图
